# Token Monitor for Mac

Token Monitor by SRG+ shows the limits of every Claude account in the Mac menu bar: session, week and model limits, how much is used and when each resets.

**Download:** [TokenMonitor.dmg](https://github.com/srgplus/token-monitor-macos/releases/latest/download/TokenMonitor.dmg) (macOS 14 or later, Apple silicon and Intel, signed and notarized by SRG PLUS INC).

Open the DMG, drag Token Monitor to Applications, open it, then click the icon in the menu bar → gear → Add account for each Claude account.

Token Monitor 1.4 and later update themselves (Settings > Check for Updates). This repository holds only the releases and the update feed (`appcast.xml`, served by GitHub Pages).
